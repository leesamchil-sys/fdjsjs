이 폴더에 시즌 이벤트 도감 설정 팝업(SeasonalSelector)에서 사용할 이미지들을 업로드해주세요.

## 이미지 권장 규격
* 비율: 1:1 정사각형 권장
* 포맷: `.png` 또는 `.jpg` (코드에서는 `.png`로 기본 매핑되어 있으나 필요시 데이터 구조에서 수정 가능)
* 크기: `120x120` 픽셀 이상 권장
